# Changelog

## 1.0.0 - 2026-11-07

First public engineering edition of WebCraft Content Automation.

- Curated production queue based on the existing Notion-to-voiceover workflow.
- New MCP research server with optional search, supplied-evidence ranking, and content briefs.
- Credential-free success and failure demonstrations.
- Node and Python regression tests, Windows/Linux CI, setup and architecture documentation.
- Historical script-generation, speech, and browser-recording modules retained under `legacy/`.
- Explicit attribution of creator-reported production and channel milestones.

This release date does not represent the start of the earlier production workflow. The MCP server is a new addition and is not retrospectively credited with the entire production history.
